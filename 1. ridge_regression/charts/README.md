# Ridge notebook charts

This folder contains PNG and SVG charts generated by `notebooks/featurewise_ridge_quality_scoring_model.ipynb` for the final Ridge model used in the report. The notebook is a standalone replica of the final Ridge model-building code path used for the thesis experiments.

The selected multiplier values from the notebook prediction preview were checked against `../final_ridge_test_metrics_multipliers_descriptors.csv` and matched for all 12 unseen test projects.

The `candidate_curves/` subfolder contains per-project candidate multiplier curve charts.
