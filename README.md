# Bimba3D-re Research Outputs

This folder contains report-ready outputs rebuilt from the actual Bimba3D-re pipeline/model artifacts.

- `1. ridge_regression/`: final Ridge Regression report outputs and Ridge comparison models.
- `2. mlp/`: final MLP report outputs and MLP comparison model.

The source pipeline snapshots may contain historical runs. The final report tables are the 12-row CSV files inside each model folder.
